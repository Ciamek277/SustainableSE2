# GreenLint

CLI that finds **energy-related Python anti-patterns** using the **`ast`** module. Savings numbers (**Joules**, **CO₂e**, **weights**) come from **`experiments/results/summary.json`** (regenerated by benchmarks). This is **not** a hardware power meter.

**Requirements:** **Python 3.10+** and a clone of this repo. Below, **`REPO`** is the folder that contains **`pyproject.toml`** (replace with your path, e.g. `~/project/SustainableSE2`).

---

## Choose how you install

| | **With a virtual environment** | **Without a virtual environment** |
|---|--------------------------------|-----------------------------------|
| **Who** | Recommended for you if you want an isolated `.venv/` folder | Fine for teammates who already use one global/user Python and don’t want a venv |
| **What you skip** | Nothing extra | Do **not** create or activate `.venv` |
| **Install command** | `python3 -m venv .venv` then `pip install …` **inside** the venv | `python3 -m pip install …` using **your** Python (no venv) |
| **Every time you open a terminal** | `cd REPO` → `source .venv/bin/activate` (see table below for Windows) | Only `cd REPO` |

Both ways end up with the same **`greenlint`**, **`pytest`**, and **`pip install -e .`** — only the **activate** step differs.

---

## Path 1 — With a virtual environment (recommended)

### 1) One-time setup

```bash
cd REPO
python3 -m venv .venv
```

Activate the venv:

| OS | Command |
|----|---------|
| macOS / Linux | `source .venv/bin/activate` |
| Windows **cmd** | `.venv\Scripts\activate.bat` |
| Windows **PowerShell** | `.venv\Scripts\Activate.ps1` |

Then install:

```bash
pip install -e .
pip install -e ".[dev]"
pip install -e ".[benchmarks]"
```

### 2) Every new terminal (before `greenlint`, `pytest`, or benchmarks)

```bash
cd REPO
source .venv/bin/activate
```

(Windows: use the **activate** command from the table above instead of `source`.)

### 3) Commands you actually run

**Lint**

```bash
greenlint benchmarks/eco1/bad.py
greenlint benchmarks/
greenlint --summary experiments/results/summary.json benchmarks/eco3/bad.py
```

**Tests**

```bash
pytest
```

**Regenerate `experiments/results/summary.json`** (slow; optional)

```bash
env -u GREENLINT_CODECARBON python experiments/run_benchmark.py --repeats 15
```

Run **`pytest`** before this if you changed code.

---

## Path 2 — Without a virtual environment

Do **not** create `.venv`. From **`REPO`** use **`python3 -m pip`** so you install into **that** Python (avoids mixing with another `pip`).

### 1) One-time setup

```bash
cd REPO
python3 -m pip install -e .
python3 -m pip install -e ".[dev]"
python3 -m pip install -e ".[benchmarks]"
```

### 2) Every new terminal

```bash
cd REPO
```

(No `source` — there is no venv.)

### 3) Same commands as Path 1

```bash
greenlint benchmarks/eco1/bad.py
greenlint benchmarks/
pytest
env -u GREENLINT_CODECARBON python experiments/run_benchmark.py --repeats 15
```

If **`greenlint`** is “command not found”, your shell does not include that Python’s **scripts** directory on **`PATH`**. Fix your PATH, or call the executable that `pip` printed at install time, or reinstall with a Python whose `bin` is on PATH.

## Quick reference

- **`--summary`** — optional path to JSON; default is **`experiments/results/summary.json`** when using editable install from **`REPO`**.
- **`env -u GREENLINT_CODECARBON`** — use for benchmarks so the **time-based proxy** runs (fewer IDE/sandbox issues than CodeCarbon hardware).
- **`experiments/results/raw_runs.csv`** — generated by benchmarks; **gitignored**.

**Exit codes (`greenlint`):** `0` = clean, `1` = warnings, `2` = path missing.

---

## Green Score

- Starts at **10**; each warning subtracts that rule’s **`weight`** from `summary.json` (default **1.0** if missing). Score is an integer in **[0, 10]**.

---

## Rules (ECO1–ECO7)

| Code | Pattern |
|------|---------|
| ECO1 | `for i in range(len(x)): x[i]` |
| ECO2 | `list = []; for: list.append(...)` |
| ECO3 | `s += ...` on strings in a loop |
| ECO4 | `x in` a slow container in a loop; prefer **set** |
| ECO5 | Unused **heavy** top-level import |
| ECO6 | `pandas` `iterrows()` |
| ECO7 | `pandas` `.apply(...)` where vectorized ops suffice |

## Benchmark details (optional)

- **`experiments/codecarbon_utils.py`** maps **duration** → proxy J / CO₂ (see **`proxy_joules_per_second`** in `summary.json`). Override with **`GREENLINT_PROXY_J_PER_S`** / **`GREENLINT_PROXY_CO2_KG_PER_S`** if you want a different numeric scale.
